# Google visibility checklist

- Primary identity: **Alvaro Petro**
- Public alias: **Alvaro P100**
- Canonical website: **https://alvarop100.github.io/**

## Implemented on the website

- Use `Alvaro Petro` as the visible real name and `Alvaro P100` as the visible online alias.
- Use both names in the homepage title, description, heading area, biography, and project attribution.
- Publish `ProfilePage` and `Person` structured data with `name`, `alternateName`, `identifier`, `sameAs`, and relevant topics.
- Connect the canonical GitHub and YouTube profiles through `sameAs`.
- Publish canonical URLs, robots directives, and an XML sitemap.
- Keep project names and descriptions connected to the same person entity.

## Free actions after deployment

1. Add `https://alvarop100.github.io/` as a URL-prefix property in Google Search Console.
2. Submit `https://alvarop100.github.io/sitemap.xml` in the Sitemaps report.
3. Use URL Inspection once for the homepage, About page, Projects page, and Scooly project page. Request indexing for each.
4. Change the YouTube display name to `Alvaro Petro | Alvaro P100` and add `https://alvarop100.github.io/` to the channel links and About text.
5. Set the GitHub account name to `Alvaro Petro`, keep `AlvaroP100` as the username, add the website URL, and mention `Alvaro P100` in the bio.
6. Put `Alvaro Petro (Alvaro P100)` in the LinkedIn headline or About section and link back to the website. Use the exact LinkedIn profile URL in the website `sameAs` list only after it is confirmed.
7. Use the same spelling and profile image across public accounts. Do not create duplicate or empty profiles.
8. Publish real project updates under the same name pair. One useful update is more valuable than many thin profile pages.

## Measurement

Check these queries weekly in an incognito window and in Search Console:

- `Alvaro Petro`
- `"Alvaro Petro"`
- `Alvaro P100`
- `"Alvaro P100"`
- `Alvaro Petro developer`
- `Alvaro P100 Scooly`

Record the date, indexed URL, approximate position, and whether the title correctly connects both names. Search results can take days or weeks to change, and indexing does not guarantee a ranking.
