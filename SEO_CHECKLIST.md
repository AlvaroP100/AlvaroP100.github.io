# Google visibility checklist

- Primary identity: **Alvaro Patru**
- Public alias: **Alvaro P100**
- Canonical website: **https://alvarop100.github.io/**

## Implemented on the website

- Use `Alvaro Patru` as the visible real name and `Alvaro P100` as the visible online alias.
- Use both names in the homepage title, description, heading area, and biography.
- Publish `ProfilePage` and `Person` structured data with `name`, `alternateName`, `identifier`, `sameAs`, and relevant topics.
- Connect the canonical GitHub, LinkedIn, and YouTube profiles through `sameAs`.
- Publish canonical URLs, robots directives, and an XML sitemap.
- Keep project pages out of the sitemap and mark them `noindex` until they are ready to be promoted.

## Free actions after deployment

1. Add `https://alvarop100.github.io/` as a URL-prefix property in Google Search Console.
2. Submit `https://alvarop100.github.io/sitemap.xml` in the Sitemaps report.
3. Use URL Inspection for the homepage and About page. Request indexing for each.
4. Change the YouTube display name to `Alvaro Patru | Alvaro P100` and add `https://alvarop100.github.io/` to the channel links and About text.
5. Set the GitHub account name to `Alvaro Patru`, keep `AlvaroP100` as the username, add the website URL, and mention `Alvaro P100` in the bio.
6. Put `Alvaro Patru (Alvaro P100)` in the LinkedIn headline or About section and link back to the website. Use the exact LinkedIn profile URL in the website `sameAs` list only after it is confirmed.
7. Use the same spelling and profile image across public accounts. Do not create duplicate or empty profiles.
8. Keep public descriptions capability-focused until individual project pages are ready for indexing.

## Measurement

Check these queries weekly in an incognito window and in Search Console:

- `Alvaro Patru`
- `"Alvaro Patru"`
- `Alvaro P100`
- `"Alvaro P100"`
- `Alvaro Patru developer`
- `Alvaro Patru cybersecurity`

Record the date, indexed URL, approximate position, and whether the title correctly connects both names. Search results can take days or weeks to change, and indexing does not guarantee a ranking.
