# alvarop100.github.io

The source for the personal website of Alvaro Patru, also known online as Alvaro P100.

The site is built with Jekyll and hosted free on GitHub Pages. It includes:

- A homepage and biography centered on software, infrastructure, data, security, automation, and AI capabilities
- Search metadata, canonical URLs, Open Graph cards, and an XML sitemap
- `ProfilePage`, `Person`, and `CreativeWork` structured data
- A canonical identity connection between Alvaro Patru, Alvaro P100, GitHub, LinkedIn, and YouTube
- Responsive light and dark themes
- No analytics, advertising, or paid hosting dependency

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Open `http://127.0.0.1:4000`.

## Content

Core identity information and public profile links live in `_data/profile.yml`. Project pages remain available in the repository but are intentionally excluded from indexing for now.

The production URL is [alvarop100.github.io](https://alvarop100.github.io).
